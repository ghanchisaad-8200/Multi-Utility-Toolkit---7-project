# Multi-Utility Toolkit 🛠️

## 📌 Project Description

Multi-Utility Toolkit is a Python-based project developed using Python's built-in modules. It provides multiple useful utilities through a simple menu-driven interface.

This project demonstrates the use of Python modules, functions, file handling, random operations, date and time operations, and UUID generation.

## ✨ Features

- **Date and Time**
  - Display current date and time
  - Show calendar
  - Calculate age

- **Math Operations**
  - Calculate factorial
  - Calculate compound interest
  - Calculate area of a circle
  - Find square root

- **Random Operations**
  - Generate random numbers
  - Select a random item from a list
  - Generate secure passwords
  - Generate OTP

- **UUID Operations**
  - Generate unique UUID
  - Generate multiple UUIDs

- **File Operations**
  - Create a file
  - Write content to a file
  - Read file content
  - Append content to a file

- **Module Explorer**
  - Explore built-in Python modules
  - Display available functions and attributes using `dir()`

## 💻 Technologies Used

- Python 3

  - `datetime`

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open Jupyter Notebook.
3. Open `Multi_Utility_Toolkit.ipynb`.
4. Run all code cells from top to bottom.
5. Run the last cell containing `main()`.
6. Select an option from the menu.
